# Tweakeroo — 客户端微调模组

**版本**: 0.17.0 | **Minecraft**: 1.20.1 Fabric | **Java**: 17

Tweakeroo 是一个 Minecraft 客户端模组，提供 76 个以上的可独立开关的功能微调。从方块放置优化到摄像机控制、从 Gamma 覆盖到物品栏管理——几乎覆盖了 Minecraft 游戏的每一个操作细节。

Forked from [sakura-ryoko/tweakeroo](https://github.com/sakura-ryoko/tweakeroo).

## 放置类功能

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| **灵活放置** | 按住修饰键 | 改变方块放置的朝向、偏移或相邻位置。Rotation/Offset/Adjacent 三个子热键 |
| **精准放置** | 按快捷键 | 简化版灵活放置，方块面朝点击面或朝外 |
| **快速方块放置** | 按住右键移动 | 光标经过新方块时自动快速连续放置，可配置每 tick 最大数量 |
| **快速右键** | 按住右键 | 自动快速右键点击 |
| **快速左键** | 按住左键 | 自动快速左键攻击/挖掘 |
| **放置限制** | 按快捷键 | 限制按特定模式放置：平面/面/列/线/层/对角线 |
| **放置网格** | 按快捷键 | 方块按网格间距放置 |
| **放置数量限制** | - | 限制每次右键最多放置数量 |
| **放置限制-首个方块** | - | 只能对着第一次点击的方块类型放置 |
| **放置限制-手中物品** | - | 只能对着手中同种方块放置 |
| **Y轴镜像** | - | 镜像点击位置在方块内的 Y 坐标（台阶上/下半切换） |
| **拿起再放置** | - | 放置前自动切换到手中对着的方块 |
| **伪潜行放置** | - | 对着交互方块放置时不需潜行 |
| **天堂方块** | - | 创造模式在空气中放置 |
| **破坏限制/网格** | 按快捷键 | 限制破坏模式（平面/面/列/线/层/对角线/网格） |
| **方块类型破坏限制** | - | 基于黑/白名单的破坏限制 |
| **实体类型攻击限制** | - | 基于黑/白名单的攻击限制 |

## 物品栏类功能

| 功能 | 说明 |
|------|------|
| **手中物品补充 (Hand Restock)** | 主手/副手物品用完后自动从背包补充 |
| **快捷栏槽位循环** | 每次放置后按顺序切换快捷栏槽位 |
| **快捷栏槽位随机** | 每次放置后随机切换快捷栏槽位 |
| **快捷栏交换** | 快捷键交换快捷栏与背包三行之一 |
| **快捷栏滚动** | 按住热键滚轮切换快捷栏对应的背包行 |
| **工具切换** | 自动切换到对目标方块最有效的工具 |
| **武器切换** | 自动切换到对目标实体最有效的武器（可自定义映射） |
| **修复模式** | 物品修好后自动切换另一个有经验修补的受损物品 |
| **不可堆叠保护** | 防止某些物品使用后意外丢失（如空桶） |
| **损坏工具替换** | 耐久将尽的工具提前自动替换 |
| **空潜影盒堆叠** | 允许空潜影盒堆叠到 64（需服务端支持） |

## 摄像机/视角功能

| 功能 | 说明 |
|------|------|
| **自由摄像机 (Free Camera)** | 类似旁观模式的自由视角，玩家本体留在原地。可配置是否允许本体移动/交互 |
| **缩放 (Zoom)** | 按快捷键缩放视野，可配置 FOV 值和鼠标灵敏度调整 |
| **滑翔翼视角** | 使用滑翔翼时锁定玩家实际旋转，鼠标只控制摄像机，可自由环顾 |
| **瞄准锁定 (Aim Lock)** | 将视角的 Yaw/Pitch 锁定在当前值 |
| **快照瞄准 (Snap Aim)** | 视角自动吸附到预设角度步长（如 45°） |
| **快照瞄准锁定** | 将视角锁定在当前吸附值 |

## Gamma/亮度功能

| 功能 | 说明 |
|------|------|
| **Gamma 覆盖** | 覆盖视频亮度值（最高 16.0，原版最大 1.0），让黑暗区域完全可见 |
| **岩浆视野** | 有水下呼吸/防火效果时大幅提高岩浆下能见度 |

## Disable 系列（禁用功能）

共 39 项可热键切换的"禁用"功能，包括：
- 禁用斧头去皮、锹修路
- 禁用告示牌 GUI、双击奔跑、触墙取消冲刺
- 禁用各种迷雾（下界迷雾、渲染距离雾、BOSS 雾）
- 禁用各种渲染（实体、粒子、信标光束、脚手架、副手）
- 禁用各种音效和视觉效果（传送门音效、视野摇晃、反胃效果）
- 禁用计分板、BOSS 栏、状态效果 HUD
- 禁用下界传送门关闭 GUI、物品栏效果渲染

## 使用方法

1. **按 `T + C`** 打开 Tweakeroo 配置界面
2. 在左侧列表浏览所有功能开关（Generic / Hotkeys / Fixes / Lists / Disable）
3. 点击功能项查看说明并切换开关
4. 快捷键在 Hotkeys 标签页中自定义绑定

**常用场景**:
- **黑暗探索**: 开启 Gamma Override（亮度拉满）+ Lava Visibility
- **精准建造**: 开启 Flexible Placement + Placement Grid
- **高效挖掘**: 开启 Tool Switch + Fast Left Click + Breaking Restriction
- **自由视角**: 开启 Free Camera 快捷键，按下进入自由摄像机模式

## 已知限制

- **快速放置/快速右键**在部分反作弊服务器上可能被检测
- **自由摄像机**退出时会有短暂的区块重新加载
- **空潜影盒堆叠**需要在服务端有对应支持，否则会导致物品不同步
- **Gamma 覆盖**设置的极高亮度只在客户端生效
- **物品栏预览**需要服务端安装了对应模组或使用了特定协议

## MRQ 分支改进

### bug 修复
| 问题 | 位置 | 修复内容 |
|------|------|---------|
| **SNAP_AIM_LAST_PITCH 配置丢失** | `Configs.java` | `OPTIONS` 持久化列表补回遗漏的字段 |
| **FeatureToggle 线程可见性** | `FeatureToggle.java` | `valueBoolean` 添加 `volatile` 修饰 |
| **共享可变 Date 竞态** | `MiscUtils.java` | 移除共享 Date 对象，SimpleDateFormat 缓存复用 |
| **正则重复编译** | `InventoryUtils.java` | `PATTERN_SLOT_RANGE` 提取为静态常量 |
| **多处空 catch** | `EntityRestriction.java`、`InventoryUtils.java`、`MixinPresetsScreen.java` | 添加 Tweakeroo.logger 日志 |

### 增强
- 完整的中文翻译
- JSON 驱动的 GUI 布局系统（可折叠分组、拖拽排序）
- 潜影盒预览时隐藏原版物品提示文字
- 工具切换优化（剪刀优先于其他工具）
- Gamma 覆盖在配置加载后正确恢复

## 与原版的区别

| 方面 | 原版 | MRQ |
|------|------|-----|
| SNAP_AIM_LAST_PITCH | 配置重启后丢失 | ✅ 持久化保存 |
| valueBoolean 可见性 | 无 volatile | ✅ volatile 修饰 |
| SDF/Date 线程安全 | 共享可变对象 | ✅ 缓存 + 局部对象 |
| Pattern 编译 | 每次调用编译 | ✅ 静态编译 |
| 空 catch 块 | 静默忽略 | ✅ 带异常日志 |
| 中文翻译 | 无 | ✅ 完整简体中文 |
| GUI 布局 | 固定布局 | ✅ JSON 自定义布局 |
